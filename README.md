# Gecode - LNS Ising Automatic Model Relaxation and Multi-Armed Bandits

This repository contains an extension of the CP 25 solver, which in turn is an extension of [the Gecode-based information-sharing portfolio solver of Dexter Leander](https://github.com/ddxter/gecode-dexter), which was part of [his master thesis](https://www.diva-portal.org/smash/record.jsf?pid=diva2%3A1876143&dswid=-6428). 

This extended solver was used for running the experiments for the Automatic Relaxation and Multi-Armed Bandit Learning for Large Neighbourhood Search paper.
